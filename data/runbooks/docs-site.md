## Publishing checklist

1. Check links and Markdown syntax.
2. Keep examples consistent with the code they describe.
3. Remove credentials and private operational details.
4. Document the validation command beside contribution instructions.

## CI is not configured

The committed sample has state `never`, with no workflow or reference. This is
not a passing run. The workshop starter intentionally labels it incorrectly
so participants can reproduce and fix a small, disclosed correctness defect.

## Correct behavior

The portal should display **Not configured**. A missing workflow remains an
Attention finding after the label is fixed. A presentation fix cannot create CI.
